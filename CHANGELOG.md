# Changelog

All notable changes to the SiNC project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-11-13

### Official Release for LOGICODIX 2026 Hackathon

#### Added
- Full interactive 3D CNC Lathe machine simulator built with Three.js.
- 2D CNC control panel simulator modeled after industrial GSK and Gremat lathe standards.
- Cinematic camera transition connecting 2D panel programming and real-time 3D cutting simulation.
- Dual-theme interface design: Light Blueprint mode (instructional) and Dark Cockpit mode (focused workshop).
- Serverless backend architecture using Google Cloud Firestore for real-time document storage.
- AI Tutor integration powered by Google Gemini 3.5 Flash-Lite for G-Code debugging and guidance.
- Complete Learning Management System (LMS) modules for Administrator, Teacher, and Student roles.
- Automated G-Code verification and evaluation engine with dimension accuracy checks.
- Comprehensive system architecture, use case, activity, and entity-relationship diagrams.
- Production deployment on GitHub Pages with automated continuous deployment.
- Open source MIT License documentation and attribution.
